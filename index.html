ถ่ายด้วย iPhone

ถ่ายแล้วไม่เห็นรูปจนกว่าจะล้างฟิล์ม เหมือนกล้องฟิล์มจริง

หรือตั้งใน X-T1 · กด Q แล้วตั้งตามนี้
เก็บไว้ช่องไหน
วิธีตั้งในกล้อง
  1. WB Shift: เลือกช่อง WB ใน Q → เลือกโหมด → กด MENU/OK → ซ้าย/ขวา = R, ขึ้น/ลง = B
  2. เก็บถาวร: MENU → EDIT/SAVE CUSTOM SETTING → เลือก C1–C7 → SAVE CURRENT SETTINGS
  3. เปลี่ยนม้วนตอนถ่าย: กด Q → ช่องมุมซ้ายบน (BASIC/C1–C7) → หมุนแป้นเลือก
  4. Exp. Comp.: ตั้งที่แป้นชดเชยแสงบนตัวกล้อง

สูตรเป็นค่าประมาณจากโทนของฟิล์มแต่ละม้วน X-T1 ไม่มี Grain Effect เกรนได้จาก ISO สูงกับ NR −2 DR200 ต้องใช้ ISO 400 ขึ้นไป DR400 ต้อง ISO 800 ขึ้นไป Classic Chrome ต้องใช้ firmware 4.00 ขึ้นไป ลองถ่ายแล้วปรับ WB Shift ตามแสงจริง
